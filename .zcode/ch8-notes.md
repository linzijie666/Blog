# 第八章 SI&PI 内容笔记

## 1. PI / PDN（p4–20）
- SI 是驱动端到接收端波形幅值、形态与时序的完整程度；常见问题：串扰、阻抗不连续与反射、插损/衰减、时延与等长、EMC、电源相关问题。
- PI 是电源到负载芯片在工作频段内提供稳定低噪声电压电流的能力。目标阻抗 `Ztarget=ΔV/ΔI`；例 3.3V、允许 5%、电流阶跃 1A，目标 0.165Ω（注意是频段内阻抗，不是直流电阻）。
- PDN 五部分：VRM（0~10kHz）、去耦电容（10k~100MHz）、板级平面对（约 10MHz~1GHz）、封装、片上电容。不同容值/封装并联覆盖频段。
- SSN：`ΔV=N×Lloop×Δi/Δt`，大量 IO 同时翻转造成 ground/power bounce，DDR DQ 数量和速率越高眼图越差。对策：增加电源/GND 层、拓宽平面、贴近负载增加不同封装去耦、优化编码/错峰。
- 核心电源与 DDR VTT 用 VSENSE 远端差分反馈，采样点在芯片 BGA 供电端，Sense 线成对 Kelvin 回到控制器。
- 去耦：每个电源脚至少一颗就近小电容；小容值配小封装、短粗连接；平面不要被过孔阵列割裂，换层多打电源/地过孔降低寄生电感。
- 地弹不能只靠电容解决：AGND/GND/PGND 按功能分区并单点连接，功率地与控制地隔离；分电源用单点或磁珠隔离，避免通道间互扰。

## 2. 传输线、反射与端接（p20–36）
- 传输线是分布电容/电感，特征阻抗由单位长度 L/C 与介质决定，与信号频率、线长本身、寄生电感无直接关系。微带阻抗受线宽 W、铜厚 t、介电常数 εr、层距 h 影响。
- 连续完整参考平面保证回流。常见阻抗：单端 50Ω；LVDS/MIPI/HDMI/千兆 MDI 100Ω；USB 90Ω；PCIE 80~90Ω。
- 反射系数 `ρ=(Z2-Z1)/(Z2+Z1)`；开路 ρ=+1，末端电压翻倍；短路 ρ=-1，末端电压抵消。多次往返反射形成振铃与台阶。
- 端接：源端串 22~33Ω（驱动约 30Ω，与 50Ω 配平）；并联端接耗直流；戴维宁端接兼做共模偏置；RC 端接隔直流；DDR fly-by 菊花链末端 40~50Ω 到 VTT；DDR4 差分时钟可 2×36Ω+10nF RC；LVDS 外部 100Ω 或芯片内部端接只能选其一。
- ODT 从 DDR2 起，由寄存器切换 DQ/DQS/DM 内部端接，方向随读写变化；节省布线且接近 die，但受工艺温度影响。

## 3. 高速判断与测量（p36–45）
- 正弦频率等于带宽；近似方波按 10%~90% 上升时间 `BW=0.35/tr`。25MHz、4ns 上升沿实际带宽约 90MHz。
- 示波器带宽通常取信号频率/等效带宽的 5~7 倍，以保留上升沿细节；千兆 MDI 125MHz 需约 1GHz。
- 判高速：速率本身高；上升沿陡且有 tr/tf 约束；链路有严重趋肤/介质损耗；或 PCB 长度超过上升沿带宽对应波长的 1/6。W9825G6KH tr=1ns→BW=350MHz，FR4 约 1.5e8m/s，λ≈0.42m，1/6≈70mm。
- 插损与频率、距离近似成正比；VNA 测 S21 插损、S11 回损，先两端口校准再扫频。
- TDR 发阶跃并观察反射，时间轴映射物理距离；窄线/高阻向上，宽线/低阻向下，开路趋无穷。可定位连接器、断路、短路与阻抗突变。

## 4. 等长（p45–67）
- 根本原因是采样沿的 setup/hold；数据应相对本组采样时钟等长，不是任意数据互比。等长本质是“等时”，要考虑 PCB 内外层速度、过孔、封装 pin delay，最好同层并一起换层。
- DDR：地址命令相对 CK；每 Byte 的 DQ/DM 相对 DQS；LPDDR4 3200Mbps 约要求 ≤16ps（约 100mil）。eMMC 相对 CLK/Data Strobe；RGMII TX/RX 各相对本向时钟 ±120mil；SPI/并口相对 SCLK/PCLK。
- 差分 P/N 对内一般 ±5mil；P/N 不等会把差模转成共模，压缩眼图并增加 EMI。MIPI/LVDS/HDMI 2.0 要按独立时钟做组内等长。
- USB、PCIE、DP、千兆网用 CDR/内嵌时钟，只做 P/N 对内等长，不做不同差分对之间等长。
- PCB 实现：以时钟设 target/match group；长线预留补偿；就近补偿优于集中在一端；P/N 一起绕、间距不超过正常间距两倍；蛇形中心距尽量 ≥3W/4W，避免自耦；绕线少、并行段短；器件/过孔布局必须对称。

## 5. SI 传输路径（p67–87）
- 阻抗连续：按主控/协议表控制 50/85/90/100Ω；BGA 扇出区可短暂缩线宽/线距，出区立即恢复阻抗结构。
- 完整低阻 GND 参考优先于电源参考；不要跨分割或换参考网，无法避免时在近处放 stitching capacitor。
- 换层时加伴地孔；高速差分每对至少 2 个对称伴地孔。若参考从 L2 GND 换到 L5 GND，伴地孔缩短回流，否则绕远增加阻抗与 EMI。
- 通孔残桩造成谐振与反射。≥5Gbps、换层多时考虑背钻或 HDI 盲埋孔；普通 PTH 每 TX/RX 通道常≤2 个。焊盘下局部挖参考平面补偿焊盘/电容/连接器导致的额外电容。
- 差分扇出、耦合器件与过孔保持对称；弯角用圆弧或 45°；差分对间建议 5W，普通信号 3W；相邻层拉开 4~6H 或正交。
- 高速板材看低 Df、低 CTE、高 Tg；跨板优先完整参考 FPC/板对板连接器，长距离用同轴/双芯同轴/屏蔽双绞线。均衡器/Redriver 只补幅频，Retimer 还能重整时钟和抖动。
- 玻纤效应：P/N 走在玻纤束与树脂上导致介电常数不同；用旋转布线、zigzag 或选更均匀玻纤布，制造后 TDR 验阻抗。

## 6. 眼图、ISI、抖动与均衡（p88–98）
- 眼图把大量比特按 UI 叠加；同时观察多个码型/周期的 worst case。眼高反映幅值、插损、噪声；眼宽反映可采样时间和抖动。1UI=1/Tbit，10Gbps 时 1UI=0.1ns。
- 眼图模板规定禁入区域，必须按协议指定测试点、夹具和终端；HDMI 1.4 示例在发送端连接器 TP1 外接上拉测试。
- ISI 来源：不同码型频谱不同，链路高频插损更大，使 0101 比 111000 衰减更严重，眼高眼宽下降。
- 接收均衡相当于高通+增益，衰减低频、增强高频以抵消信道损耗；DS25BR110 2.5Gbps/70inch FR4 经 EQ 后眼图重开。
- 预加重提高第一个跳变 bit；去加重降低连续相同比特的后续幅值，本质都是平衡高低频分量。PCIE3、USB3、HDMI1.4+ 等使用。

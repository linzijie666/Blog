# 新增第七章（高速接口）与第八章（SI&PI）共 12 篇复习文章

沿用现有六章的既定模式（章级 PDF 下载 + 裁切配图 + 正文组件 + 注册表 + 测试 + README）。

## 章节与文章规划

**第七章 `high-speed-interfaces`「高速接口」** — 源课件 66 页（OneDrive\图文课件-第七章-高速接口）：
1. `iic-spi` IIC 与 SPI：协议、开漏输出、上拉电阻选择、多从机扩展（p4–18）
2. `setup-hold-time` 建立时间与保持时间：定义、计算与测量；示波器 vs 逻辑分析仪（p19–24）
3. `rs232-rs485` RS232 与 RS485：电平、电路设计与波形解读、IIC/SPI/UART 对比（p25–33）
4. `lvds` 差分信号与 LVDS：优点、电气标准、等长与长距离衰减（p34–44）
5. `gigabit-ethernet` 千兆网接口：PHY、RGMII/MDIO、网络变压器与 RJ45（p45–54，并入附加 PDF《千兆网 1000BASE-T》有文本层内容：RGMII 12 线 125MHz DDR 2ns 延时、MDIO 上拉、Bob Smith 端接、PHY 电源架构）
6. `hdmi-pcie-usb` HDMI、PCIe 与 USB：电路设计与 PCB 设计（p55–66）

**第八章 `si-pi`「信号完整性与电源完整性」** — 源课件 98 页（OneDrive\图文课件-第八章-SIPI…）：
1. `pi-pdn` 电源完整性：PDN 组成、VRM、去耦电容与板级电容、PI 问题与解决（p4–20）
2. `transmission-line-termination` 传输线与特征阻抗：反射计算、源端/并联/戴维宁/RC 端接、差分端接与 ODT（p20–36）
3. `si-measurement` 高速信号判断与测试：信号带宽、插损与 VNA、特征阻抗与 TDR（p36–44）
4. `length-matching` 等长设计：以谁为基准、哪些线要等长、单端/差分等长与蛇形实现（p45–67）
5. `si-routing` 高速传输路径设计：阻抗连续、完整参考平面、伴地孔、背钻/HDI、玻纤效应、阻抗精度（p67–87）
6. `eye-diagram-jitter` 眼图：眼高眼宽与模板；码间干扰、抖动、均衡与预加重/去加重（p88–98）

## 实施步骤

1. **章 PDF**：复制两章源 PDF → `public/downloads/high-speed-interfaces-review.pdf`（66 页）、`si-pi-review.pdf`（98 页）。
2. **配图管线**：新建 `scripts/build_high_speed_interface_article_assets.py`、`scripts/build_si_pi_article_assets.py`（照抄 analog 版：CROPS 表 `{名称: (页码,(l,t,r,b))}`、页数校验 66/98、`.webp` 长边 1400 q84 + `-hd.jpg` 长边 2200 q92）。注意两章页面为 4762×6735（第六章是 4160 宽），裁切框按实际尺寸标定。逐页阅读课件 JPG 选定每篇 3–6 张配图（共约 60–80 组），运行脚本后逐一目检裁切效果并修正。
3. **12 篇正文**：`src/knowledge/articles/` 新建 IicSpiArticle、SetupHoldTimeArticle、Rs232Rs485Article、LvdsArticle、GigabitEthernetArticle、HdmiPcieUsbArticle、PiPdnArticle、TransmissionLineTerminationArticle、SiMeasurementArticle、LengthMatchingArticle、SiRoutingArticle、EyeDiagramJitterArticle。遵循现有模式：section id 与注册表对齐、末尾 `interview` 节（details/summary ≥3）、`ArticleFigure` 四属性齐全（sourcePage 对应课件页码）、计算主题配 `WorkedExample`（IIC 上拉电阻、建立/保持裕量、反射系数、端接电阻等）、公式用 `FormulaText`（`_{}` 只出现在字符串属性内）。
4. **注册表** `articles.js`：`knowledgeChapters` 追加两章；`reviewArticleDefinitions` 末尾（vref-precision 之后）追加 12 篇定义——数组顺序即上一/下一链条。

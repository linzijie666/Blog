# 电容与电感知识专栏页面设计

## 目标

在现有个人作品集首页中，用“知识专栏”替换底部 Contact 大区块，并发布第一篇独立文章《电容“隔直通交”与电感“通直隔交”的原理》。内容面向通信工程专业学生，采用课堂笔记型深度，预计阅读时间 5 至 8 分钟。

## 范围

本次改动包括：

- 将首页导航中的 `Contact` 改为 `Knowledge`，锚点指向知识专栏。
- 将首页底部 Contact 大区块替换为知识专栏区块。
- 在知识专栏区块展示第一篇文章卡片，并保留以后增加文章的扩展位置。
- 新增独立文章视图，地址使用 `#/knowledge/capacitor-inductor`。
- 保留页头邮箱按钮和右下角浮动邮箱入口，不删除现有联系方式。
- 增加与本功能相关的自动化测试。

本次不引入内容管理系统，不增加后台编辑功能，不重构项目展示区，也不修改现有项目数据。

## 信息架构与导航

首页仍是网站默认入口。用户可以通过顶部 `Knowledge` 导航滚动到首页底部知识专栏，也可以在自然浏览到页面底部时看到文章卡片。

文章卡片展示：

- 分类：电路基础
- 标题：电容“隔直通交”与电感“通直隔交”的原理
- 摘要：从时域微分关系和频域阻抗两条线理解电容、电感对直流与交流的不同表现。
- 阅读信息：课堂笔记、约 5 至 8 分钟
- 行动入口：阅读全文

点击文章卡片进入 `#/knowledge/capacitor-inductor`。文章页提供：

- 返回首页的品牌入口
- 返回知识专栏的明确按钮
- 保留邮箱联系入口

采用轻量 Hash 路由，不增加路由依赖。这样可以兼容当前 Vite 项目、GitHub Pages 子路径和页面刷新，也不会要求服务端配置 URL 重写。

## 首页知识专栏设计

知识专栏替换原 Contact 大区块，继续承担首页收尾作用。区块沿用现有深色背景、青色强调色和工程网格语言，但从“联系号召”改为“继续阅读”的编辑型收尾。

布局由栏目标题、简短介绍和文章卡片组成。首篇文章卡片采用宽幅不对称布局，左侧为标题与摘要，右侧用电容、电感符号、阻抗公式和频率方向构成简洁技术视觉。视觉元素由 HTML 与 CSS 排版完成，不新增外部图片资源。

设计参数为：

- 变化度：5
- 动效强度：3
- 信息密度：5

动效只用于悬停反馈和轻微入场层级，并遵守现有 `prefers-reduced-motion` 降级规则。

## 独立文章页面设计

文章页使用独立 React 组件，避免继续扩大 `App.jsx`。页面与首页共享品牌、色彩和基础布局变量，但采用更适合长文阅读的窄正文栏。

文章结构如下：

1. 一句话纠正常见简称：电容和电感不是无条件地“通”或“隔”。
2. 电容的物理直觉与充放电过程。
3. 电容时域关系 `i = C du/dt`。
4. 电容频域阻抗 `Z_C = 1/(jωC)` 与容抗随频率变化。
5. 电感的磁场储能与楞次定律直觉。
6. 电感时域关系 `u = L di/dt`。
7. 电感频域阻抗 `Z_L = jωL` 与感抗随频率变化。
8. 电容、电感对比表。
9. 直流接通瞬间与稳态的区别。
10. 通信工程中的耦合电容、去耦电容、射频扼流圈和 LC 滤波应用。
11. 实际器件的 ESR、ESL、直流电阻、自谐振频率等非理想因素。
12. 记忆总结和延伸思考。

公式使用可访问的文本与 HTML 结构呈现，不引入 MathJax 或 KaTeX。电路和趋势示意使用 CSS 布局、箭头和语义文本完成，确保移动端仍然可读。

## 组件边界

计划新增以下职责清晰的模块：

- `KnowledgeSection`：首页知识专栏及文章卡片。
- `KnowledgeArticle`：独立文章页面整体结构。
- `ArticleHeader`：文章标题、元信息和返回入口。
- 小型说明组件：公式块、提示框和电容电感对比区域。

Hash 路由解析保持简单：当前地址匹配文章路径时渲染文章页，否则渲染原首页。不存在的 Hash 路径回退到首页，不显示空白页。

## 响应式与可访问性

- 桌面端文章正文保持适合阅读的行长，正文栏不铺满宽屏。
- 首页宽幅文章卡片在小屏幕下变为单列，视觉区排列在正文之后。
- 公式块允许横向滚动或自然换行，不撑破视口。
- 所有交互入口使用链接或按钮语义，键盘可达并具有清晰焦点状态。
- 标题层级从 `h1` 到 `h3` 连续，文章使用 `article`、`section` 和 `nav` 语义结构。
- 保持现有低动态偏好支持。
